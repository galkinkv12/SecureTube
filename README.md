# 🛡️ SecureTube

> **Приватный локальный видеоплеер в стиле YouTube**  
> Карточки с превью, поиск, категории, очередь «Далее», темы оформления и изолированный просмотр сайтов.  
> *Все видео, превью и настройки хранятся только на вашем компьютере — без аккаунтов, слежки и рекламы.*

## ⚡ Быстрый старт (Windows 10/11)

**Требования:** Python 3.9–3.12 ([python.org](https://www.python.org/), обязательна галочка *Add Python to PATH*).  
*Интернет необходим только при первой установке компонентов.*

| Что нужно | Что запустить |
| :--- | :--- |
| **Просто попробовать** (без сборки) | `run.bat` |
| **Собрать EXE**, установить, создать ярлыки | `build_exe.bat` |
| **Один файл `SecureTube.exe`** (вместо папки) | `build_exe.bat onefile` |
| **Ярлык** для уже установленной программы | `make_shortcut.bat` или *Настройки → Ярлык на рабочем столе* |
| **Удалить программу** (данные сохраняются) | `uninstall.bat` |

> ℹ️ **Примечание:** `build_exe.bat` собирает программу и копирует её в `%LOCALAPPDATA%\Programs\SecureTube` (служебная папка `_internal` скрыта), создавая ярлыки на рабочем столе и в меню «Пуск». Режим по умолчанию запускается быстрее, чем `onefile`, которому требуется время на распаковку при каждом старте.

## 🎨 Расширения (Темы и Акценты)

В боковой панели доступен раздел **Расширения**:
* **70+ тем:** Тёмные, светлые, AMOLED, ретро, брутализм (скругление 0), «пузырь» (скругление 24) и др.
* **20+ акцентов:** Перекрашивают интерфейс поверх любой выбранной темы.
* Применяется мгновенно без перезапуска и запоминается автоматически.
* Включает фильтр «тёмные/светлые» и кнопку «Случайная тема».

### 🛠️ Особенности кастомизации
* **Безопасность:** Расширения — это обычные JSON-файлы без кода. Они меняют только цвета и скругления, не имея доступа к видео и данным.
* **Своя тема:** Достаточно указать 4 цвета (`bg`, `text`, `accent`, `accent2`), остальные вычисляются автоматически.
* **Управление:** Кнопки «Установить из файла», «Открыть папку» и «Обновить» находятся на вкладке «Управление».
* **Сохранность:** Свои файлы хранятся в `%LOCALAPPDATA%\SecureTube\ext` и сохраняются при обновлениях программы.
* **Предпросмотр:** Все темы доступны на скриншоте `docs/themes_preview.png`.

## 🌐 Сайты: Безопасный просмотр

Раздел **Сайты** в боковой панели позволяет подключать веб-ресурсы через каталог или по адресу. Они открываются во встроенном изолированном браузере (Chromium / QtWebEngine).

**Архитектура безопасного доступа (MCP-коннекторы):** Каждый сайт описан файлом с явными правами (`extensions/sites/*.json`). При добавлении программа запрашивает подтверждение разрешений.

### 🔒 Гарантии безопасности
* **Строгая политика доменов:** Загрузка данных разрешена только с одобренных доменов. Чужие CDN, реклама и трекеры блокируются. Кнопка **«Щит»** позволяет управлять блокировками.
* **Только HTTPS:** Автоматическое повышение `http://` до `https://`. Заблокированы схемы `file:`, `javascript:`, `data:`, авторизация в URL, нестандартные порты, IP-адреса, локальные сети (`localhost`, `192.168.*`) и homograph-атаки.
* **Полная изоляция:** Каждая сессия использует изолированный профиль в памяти (cookies и кэш сбрасываются при закрытии). Вкладка закрывается при сворачивании или блокировке.
* **Защита от утечек:** Отключены камера, микрофон, геолокация, уведомления, загрузки, WebGL, буфер обмена и плагины. Заголовки `DNT` и `Sec-GPC` включены по умолчанию.

## 🎬 Основной функционал

* **Добавление:** Кнопка «＋ Добавить видео», кнопка «Папка» или Drag-and-Drop файлов/папок. Автоматический пропуск дубликатов.
* **Карточки:** Генерация превью (~10% ролика), отображение названия, длительности, даты и категорий.
* **Библиотека:** Поиск, 7 вариантов сортировки, управление категориями, избранное.
* **Плеер:** Перемотка кликом, регулятор громкости и скорости (0.5x–2x), полноэкранный режим с автоскрытием панелей, очередь воспроизведения, запоминание позиции.
* **Безопасность:** Защита паролем (scrypt), блокировка на 24 часа после 3 неверных попыток, автоблокировка при бездействии, защита от захвата экрана.

## 📂 Структура данных

Все пользовательские данные хранятся изолированно от исполняемых файлов:

```text
%LOCALAPPDATA%\SecureTube\
├── core\
│   ├── kk.bin      # Главный ключ (защищён Windows DPAPI)
│   ├── st.dat      # Состояние входа (HMAC)
│   ├── lib.xt      # Зашифрованная библиотека
│   └── cfg.xt      # Зашифрованные настройки
├── cache\          # Зашифрованные превью (<id>.xt)
└── media\          # Обезличенные копии видео (<id>.mp4)
```

## 🔐 Модель защиты

1. **Шифрование данных (AES-256-GCM):** Ключ генерируется при первом запуске, уникален для каждого ПК и защищён механизмом Windows DPAPI.
2. **Изоляция:** Перенос папки данных на другой ПК или под другую учётную запись делает данные недоступными для чтения.
3. **Хранение медиа:** Метаданные, превью и настройки зашифрованы. Видеофайлы хранятся в скрытой директории под случайными GUID-именами.
4. **Конфиденциальность:** Полное отсутствие сетевых запросов, аналитики и метрик со стороны самого приложения.

## 🔄 Миграция и обновление

* **Переход с XXXtube:** При первом запуске SecureTube автоматически переносит данные из `%LOCALAPPDATA%\XXXtube` в новую директорию. Все видео, настройки и пароли сохраняются.
* **Перенос из privplayer:** Видео из папки `videos/` можно импортировать через кнопку «Папка». Старая база данных `data/` не поддерживается и создаётся заново.
